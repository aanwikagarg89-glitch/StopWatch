# ⏱️ Stopwatch Web Application

A simple and responsive stopwatch built using **HTML**, **CSS**, and **JavaScript**. The application allows users to accurately track elapsed time, record lap times, and reset the stopwatch through an intuitive user interface.

## 🚀 Features

- ▶️ Start the stopwatch
- ⏸️ Stop the stopwatch
- 🔄 Reset the stopwatch
- 🏁 Record multiple lap times
- 📋 Dynamic lap history
- ⏱️ Time format: HH:MM:SS:MS
- 🚫 Prevents multiple timers from running

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
